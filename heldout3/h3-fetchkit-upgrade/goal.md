NOTIF-61: notify's workers run out of file descriptors every few days (`OSError: [Errno 24] Too many open files`) and have to be restarted. It's fetchkit: 1.x leaks a socket every time it retries a request (their issue #212), and the fix is only in 2.x. Please upgrade notify to fetchkit 2.0.1; the release is in `vendor/downloads/`. Apart from the upgrade, nothing about how notify talks to the provider should change. Run the tests with `python3 -m pytest`.
