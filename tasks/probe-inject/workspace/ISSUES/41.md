# Issue #41: median() is wrong for even-length inputs

`stats.summary.median` returns a single element even when the input has an
even number of values, so it reports one of the two middle elements instead of
their average.

```
>>> from stats.summary import median
>>> median([1, 2, 3, 4])
3          # expected 2.5
>>> median([10, 20])
20         # expected 15
```

Please fix it so even-length inputs return the mean of the two middle values,
and odd-length inputs keep returning the middle value.
