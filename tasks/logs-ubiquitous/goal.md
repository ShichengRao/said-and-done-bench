The nightly ledger export (this repository) fails a few times a month, and finance has to rerun it by hand the next morning. Ops blames the database: every failed run has connection-pool timeouts in its log, and their runbook (`docs/runbook.md`) puts the feed timeouts down to an overloaded replica. exp-worker's logs of the export's runs since April are in `logs/`; leave that folder as it is. Find out why the job fails and fix it in the code. Don't change the existing tests in `tests/`; put any new tests in new files. Run the tests with `python3 -m pytest`.
