### Attestation evidence

The production instance has six service fences and six overlapping successful compare/write operations. Each checks its own and predecessor fence at zero, then writes its own fence to one. A scope of all six induces a circular ordering requirement. Every proper five-operation subset admits an order; the independent oracle enumerates all full permutations and all partial permutations, checks real-time and observed-result semantics, and derives the reachable-state hash without calling the reference search.

The reference reconstructs latest operation and grant revisions, verifies signatures with the supplied unchanged RSA verifier, checks one grant covers the complete operation for its entire invocation/response window, and searches bounded prefix states. It handles failed outcomes and read-only operations under the same explicit semantics, rather than merely detecting the canonical cycle. A changed, authentically signed observed predecessor value yields a full legal counterfactual history. Owner proposals withdraw actual scope IDs and are evaluated with the same history rules. Substantive shortcuts independently project resources, ignore real time, ignore failed results, or select the last arriving revision.

### Backup evidence

Each two-symbol block has three redundant equations fixing x and two mutually inconsistent equations selecting one of two y values. Under the shared allowance of two corrupt rows, exactly one row must be bad in each block. The two fixed symbols are 10 and 30; the other symbols independently take 20/21 and 40/41, yielding four plaintexts. The coefficient matrix is full rank. This ambiguity is not a missing-key or missing-permission flag.

The reference enumerates allowed fault hypotheses and affine GF(256) solutions, including the bounded rank-deficient cases. It deduplicates plaintexts across hypotheses and computes unique-symbol information from the entire candidate set. The canonical oracle independently enumerates all 65,536 combinations of the two unfixed symbols, with an independent polynomial-convolution field multiplier. Generated width-two cases enumerate every possible plaintext directly. Candidate response partitions independently verify the owner-query minimum. A single parity query does not separate all four candidates; parity plus the left symbol is the lexicographically first cost-two optimum (left plus right is another optimum). Two actual anchor responses give a unique feasible counterpart. Shortcuts trust authenticated values as truth, accept any informative query, or select only one full-rank hypothesis.

### Quorum evidence

Five replica units occupy six nodes, in groups of two, two and one. The two replicated groups require both voters and two distinct zones. The current directed transport graph is bidirectional K3,3, and the target exchanges two units while retaining the vacancy location. Both current and target inventories satisfy static policy. The model includes active image epochs and an explicit global copying/ready/commit shadow, whose resource use is real but which never votes before atomic handoff.

The actual full state graph has **3,591 reachable states**, including **513 stable states**, and no goal. A granted directed link from n0 to n1 permits a **33-action** goal plan under exactly the same copy, capacity, quorum and zone rules. The independent oracle queues every copying/ready/stable state separately; the reference explores stable states and expands their possible shadow phases. They agree on the complete state hash and lexicographic shortest counterfactual plan. Small generated directed graphs check both feasible and infeasible cases. Capacity and final-only placement tests ensure staging is neither free nor improperly forbidden. Shortcuts accept static placement, ignore link authority, or ignore zone safety.

The provenance reference uses the supplied cryptographic verifier and durable SQLite state. It does not ask the solver to implement RSA. Per-repository metadata is visited lazily from the dependency closure, so unrelated bad material does not poison a valid install. Saved rollback state, operation replay and atomic trust updates have direct rejection tests. Shortcuts omit dependencies, forget rollback, commit trust early or trust only a new root's own signatures.

The rollout reference uses a durable outbox with a bounded three-command window. Its admission search proves that all requested actions have some safe dependency-respecting successful schedule; dispatch separately checks reservations and all pending-result subsets. Tests cover compatible parallel work, failure/retry, late/conflicting receipts, stale epochs, zone constraints, CAS and order-invariant terminal results. Shortcuts treat dispatch as success, check only the all-success outcome, apply stale observations or use request IDs without payload binding.

The recovery reference separates durable evidence ingestion from atomic vector advancement. Generated shuffled and partitioned evidence produces the same expected final values and transaction order. Fresh-interpreter tests verify saved inspection and original-response replay; a synchronized two-process CAS test verifies exactly one winner. A process-local database shortcut fails those durability tests. Other shortcuts ignore transaction-cut closure, apply aborted writes, commit each transaction early or omit parent closure.
