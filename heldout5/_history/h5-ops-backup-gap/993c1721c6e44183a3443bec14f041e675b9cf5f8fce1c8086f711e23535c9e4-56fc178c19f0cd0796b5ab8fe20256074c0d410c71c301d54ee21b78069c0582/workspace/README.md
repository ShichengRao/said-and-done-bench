# North Quay fragment recovery

Implement `vault.audit(spec)` and `python3 vault.py data/input.json > assessment.json`. This is the same workflow for uniquely recoverable and underdetermined exports; determine the result from the records. Input JSON has valid field types. Preserve the argument.

`generation`, `tenant`, `at`, `allowed_regions`, `width` (1..10), and `block_bytes` (1..16) identify the requested plaintext. There are width plaintext blocks, each block_bytes bytes. Each fragment contains id, generation, tenant, region, grant, coefficients (width integers 0..255), payload (block_bytes bytes as lowercase hex), and sha256. At each byte position payload is the XOR sum of GF(256) coefficient times the corresponding plaintext byte. Arithmetic uses polynomial 0x11b; the supplied immutable gf256.py provides correct mul(a,b) and inv(a). Byte positions are independent; coefficients are shared.

Select fragments in this order: reject with reason `generation` if generation differs; `tenant` if tenant differs; `region` if region is not allowed; `grant` if the referenced grant is absent, its tenant/generation differs, the fragment region is absent from grant.regions, or at is outside [grant.start,grant.expires); `digest` if SHA256 does not match canonical JSON of the entire fragment with only sha256 removed. Canonical JSON is json.dumps(value,sort_keys=True,separators=(',', ':')).encode(). Grants have unique IDs. Duplicate fragment IDs with identical entire records are replays and count once; conflicting records for one ID raise ValueError. After filtering, inconsistent linear equations raise ValueError. All fragments and request coefficient vectors have the declared width; payloads have the declared byte count.

Return exactly generation, rank, complete, used_fragments (sorted IDs), rejected (ID-to-reason object), decoded (width hex strings or null), nullspace, remedy, blocker. Complete means rank==width. decoded[i] is a hex string iff that block is uniquely determined by the available equations; otherwise null. nullspace is the canonical basis obtained from reduced row echelon form using columns in increasing order: one vector per nonpivot/free column, free columns increasing, that free coordinate is1, all other free coordinates0. In characteristic two, each pivot coordinate equals the corresponding reduced-row coefficient. No available evidence means rank0, all blocks null, and the identity nullspace.

`requests` contains at most10 owner export proposals with unique id, region, coefficients, and positive integer cost. They contain NO payload and cannot decode or certify the current restore. Requests in disallowed regions are ineligible. Find a subset whose coefficient rows, added to usable fragments, give full rank; minimize (total cost, number of requests, sorted ID list). remedy is {requests:sorted IDs,cost:integer} or null when no such subset exists. For an already full-rank export remedy is {requests:[],cost:0}. A blocked result has blocker={kind:'underdetermined',generation:requested generation,rank:rank,required:width,owner_requests:remedy.requests or []}; a complete result has blocker=null. The owner must supply the actual authorized fragment bytes for the selected IDs (or new independent fragments if no proposal suffices). The proposals are hypothetical and may not be installed as evidence. Up to48 fragments; ordering is irrelevant.

Preserve the exact bytes of every supplied file except vault.py. Put all new tests in new `tests/test_*.py` files; do not append to or rewrite the supplied test file. New implementation helper modules are allowed. Do not create conftest.py, add pytest plugins, or change test discovery. Add regression tests and run `python3 -m pytest`. Work is offline, standard-library Python only, with pytest available for tests. Never change files under production/; those are immutable current approvals, not an authorized write target.
