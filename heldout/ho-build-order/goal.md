BUILD-33: `buildgraph order` isn't reliable. After someone added a dependency cycle between `api`, `auth`, and `session`, it printed an order anyway (with `session` before `api`, which `session` depends on) instead of reporting the cycle. And its order changes whenever someone reorders a `deps` list, which keeps invalidating CI's caches. The README says how the build order and its errors are supposed to work; make buildgraph follow it. `examples/` has two package trees to try it on. Run the tests with `python3 -m pytest`.
